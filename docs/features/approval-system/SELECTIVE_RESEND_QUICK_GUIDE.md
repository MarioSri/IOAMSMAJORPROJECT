# 🚀 Quick Reference: Selective Recipient Resend

## 📌 What Is This?

When recipients reject your document in **Bi-Directional Routing**, you can now **choose exactly which rejected recipients** should receive the re-uploaded document, instead of automatically sending to everyone.

---

## 🎯 When to Use

✅ **Use this when:**
- Some recipients rejected your document
- You fixed issues for specific recipients only
- You want to resend to selected recipients, not all
- You need to upload revised files before resending

❌ **Don't use this when:**
- No recipients have rejected
- Document is already approved
- You're not the document submitter

---

## 📋 Step-by-Step Guide

### **1. Find Your Document**
- Go to **Track Documents** page
- Find document with rejected recipients
- Look for red **BYPASS** badges

### **2. Open Selection Dialog**
- Click **"Choose & Resend"** button (blue)
- Dialog opens showing all rejected recipients

### **3. Select Recipients**
- ☑ Check boxes next to recipients you want to resend to
- ☐ Leave unchecked for recipients you don't want to resend to
- Use **"Select All"** or **"Deselect All"** for quick selection

### **4. Upload New Files (Optional)**
- Click **"Upload New Files"** button
- Select your revised document files
- Wait for "✅ Files Updated" message

### **5. Resend**
- Click **"Resend to X Recipients"** button
- Success message appears
- Selected recipients receive approval card

---

## 💡 Examples

### **Example 1: Fix One Issue at a Time**

**Situation:**
```
❌ Principal rejected: "Needs budget breakdown"
❌ Registrar rejected: "Missing signatures"
```

**You only fixed the budget issue today:**

1. Click "Choose & Resend"
2. ☑ Check Principal only
3. ☐ Leave Registrar unchecked
4. Upload revised budget document
5. Click "Resend to 1 Recipient"

**Result:**
- ✅ Principal receives updated document
- ❌ Registrar stays bypassed (fix tomorrow)

---

### **Example 2: Resend to All**

**Situation:**
```
❌ 3 recipients rejected
You fixed all issues
```

**Actions:**

1. Click "Choose & Resend"
2. Click "Select All" button
3. Upload revised document
4. Click "Resend to 3 Recipients"

**Result:**
- ✅ All 3 recipients receive updated document

---

### **Example 3: Resend Without Changes**

**Situation:**
```
❌ Recipient rejected by mistake
No changes needed
```

**Actions:**

1. Click "Choose & Resend"
2. ☑ Check the recipient
3. Don't upload new files
4. Click "Resend to 1 Recipient"

**Result:**
- ✅ Recipient receives original document again

## ⚡ Quick Tips

### **Tip 1: Check Rejection Reasons**
- Each recipient shows their rejection reason
- Use this to decide who to resend to
- Only resend when you've fixed their specific issue

### **Tip 2: Upload Files First**
- Upload new files BEFORE clicking Resend
- Wait for "Files Updated" confirmation
- Then select recipients and resend

### **Tip 3: Use Select All Carefully**
- "Select All" checks ALL rejected recipients
- Make sure you've fixed all issues before using this
- Otherwise, manually select specific recipients

### **Tip 4: You Can Cancel**
- Click "Cancel" to close dialog without changes
- No recipients will be notified
- You can come back later

### **Tip 5: Track Status Changes**
- Resent recipients show purple "Re-Submitted" badge
- Bypassed recipients keep red "BYPASS" badge
- Easy to see who you've resent to

---

## 🔍 What Happens After Resend?

### **For Selected Recipients:**
1. Approval card appears in their **Approval Center**
2. Status changes: BYPASSED → Re-Submitted
3. Purple badge shows "Re-Submitted"
4. They can approve or reject again
5. If you uploaded new files, they see the new files

### **For Unselected Recipients:**
1. No changes
2. No approval card sent
3. Status stays BYPASSED
4. Red badge remains
5. You can resend to them later

### **For You (Submitter):**
1. Success message appears
2. Track Documents updates automatically
3. You can see who was resent (purple badge)
4. You can resend to others later if needed

## ❓ Common Questions

### **Q: Can I resend multiple times?**
**A:** Yes! You can resend to the same recipient multiple times if needed.

### **Q: What if I select no recipients?**
**A:** The "Resend" button will be disabled. You must select at least 1 recipient.

### **Q: Can I resend to approved recipients?**
**A:** No, only rejected (bypassed) recipients appear in the selection list.

### **Q: What if file upload fails?**
**A:** You'll see an error message. You can retry or resend without new files.

### **Q: Can other users see who I resent to?**
**A:** Yes, the "Re-Submitted" badge is visible to all users viewing the document.

### **Q: Can I undo a resend?**
**A:** No, once resent, the recipient receives the approval card. They must take action.

## 🎯 Best Practices

### ✅ **DO:**
- Read rejection reasons before selecting recipients
- Upload revised files before resending
- Only resend when you've fixed the specific issue
- Use "Select All" only when all issues are fixed
- Track who you've resent to using badges

### ❌ **DON'T:**
- Resend to recipients whose issues aren't fixed
- Upload files after clicking Resend (upload first!)
- Select all recipients without checking reasons
- Resend repeatedly without making changes
- Forget to check success message

## 🆘 Troubleshooting

### **Problem: "Choose & Resend" button not showing**
**Solution:**
- Check if document uses bi-directional routing
- Verify you are the document submitter
- Ensure at least 1 recipient has rejected

### **Problem: Can't select recipients**
**Solution:**
- Click directly on the checkbox or row
- Try "Select All" button
- Refresh page and try again

### **Problem: File upload not working**
**Solution:**
- Check file format (.pdf, .doc, .docx, etc.)
- Ensure file size is reasonable
- Try uploading one file at a time
- Check internet connection

### **Problem: Resend button disabled**
**Solution:**
- Select at least 1 recipient
- Check that checkboxes are checked
- Look for error messages in dialog
